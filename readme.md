This script allows you to convert an image into ASCII art. I was bored one night and remembered a camera I saw that captures ASCII photos, and thought, “I could do that.” So I spent an hour coding this, and I’m pretty happy with how it turned out.

This was my first time using arguments in Python, and I think they add a nice bit of polish to the project. At some point, I’m planning to come back to this project and add more features. (See the [Roadmap](#roadmap).)

<!-- USAGE EXAMPLES -->
## Usage


Libraries:
- PIL
- ARGParse (Optional)

<br>

Command:
```text
python file scale -i (optional) 
```

Example:
```text
python .\ASCII-Image-Converter.py github.jpg 0.1 -i 
```
